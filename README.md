# Finvalora

Finvalora is a backend application that mimics a cryptocurrency trading platform. It provides user authentication, wallet creation, order placement, and real-time market data updates over WebSockets.

The project consists of two core backend services:
1. **Django REST Framework (Finvalora):** Handles main application logic including user signups, JWT authentication, wallet management, trading models, and OpenAPI schema generation via `drf-spectacular`.
2. **FastAPI (`realtime/` module):** Manages asynchronous WebSocket connections to stream market updates and Celery/Redis pub/sub events to 
---

## Tech Stack

* **Primary Backend:** Python 3.12, Django 5.1, Django REST Framework
* **Real-Time Streaming:** FastAPI, WebSockets
* **Database:** Sqlite 
* **Caching & Message Broker:** Redis, Celery (Beat & Worker)
* **API Documentation:** `drf-spectacular` (Swagger UI / OpenAPI)
* **Deployment:** Vercel Serverless

---

## System Architecture & Workflow

1. **User Authentication:** Sign up, log in, and obtain JWT tokens.
2. **Wallet & Balance:** Automatic wallet provisioning upon registration to track quote and base currency balances.
3. **Trading Engine:** Create market/limit orders against trading pairs with database model validation.
4. **Market Data & Background Tasks:** Celery Beat schedules market data updates, pushes jobs to Redis, and broadcasts events.
5. **FastAPI Event Loop:** FastAPI subscribes to Redis channels and streams updates to frontend WebSocket clients without blocking the main DRF thread.

## How to Run the Project

### 1. Database Migrations

```bash
python manage.py migrate

```

### 2. Run the Django REST API Backend

```bash
python manage.py runserver 8000

```

* Main API endpoints will be accessible at `http://127.0.0.1:8000/api/`

### 3. Run the FastAPI WebSocket Service (`realtime`)

```bash
uvicorn realtime.main:app --host 127.0.0.1 --port 8001 --reload

```

* WebSocket endpoint listening at `ws://127.0.0.1:8001/ws/market/`

### 4. Run Celery Worker & Beat Scheduler

In separate terminal windows with active Redis:

```bash
# Run Celery Worker
celery -A portfolio worker --loglevel=info

# Run Celery Beat Scheduler
celery -A portfolio beat --loglevel=info

```
